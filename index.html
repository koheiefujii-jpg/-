GitHubのPersonal Access Token（PAT）を設定すると、写真をクラウド保存して全デバイスで閲覧できます。

📥 Claudeの分析の使い方
  1. ボイスメモの文字起こしをClaudeとのチャットに貼り付ける
  2. ClaudeがJSON形式で分析を返す
  3. カレンダーの該当の日（または週/月/学期/年）を開いて、「📥 Claudeの分析を貼り付け」 の欄に貼り付ける
  4. 「取り込む」を押すと、ダッシュボードに反映される
📖 PATの発行手順
  1. iPhone Safari等で github.com/settings/tokens を開く
  2. 「Generate new token (classic)」をタップ
  3. Note：授業ダッシュボード など分かる名前
  4. Expiration：No expiration 推奨
  5. Select scopes：repo（フル）にチェック
  6. 「Generate token」をタップ
  7. 表示された ghp_xxxxxxxx... を 長押しコピー
  8. このダッシュボードに戻って、上の入力欄に貼り付け→保存
⚠️ PATはそのデバイスのみに保存されます。iPhoneとMacなど複数デバイスで使う場合、それぞれで設定してください。
📤 ローカル写真の一括同期

このデバイスにだけ保存されている写真を、まとめてクラウドにアップロードします。完了すれば他のデバイスからも見られます。

💡 PAT設定後は、これから追加する写真は自動でクラウドに保存されます。過去の写真は上の「📤 一括同期」ボタンでまとめてアップロードできます。
